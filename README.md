# nekoai-privacy

Public hosting for the privacy policy of NekoAI, a mobile app by Day Dream Corp, served by GitHub Pages at
https://daydreamcorp.github.io/nekoai-privacy/ (Google Play needs a publicly reachable privacy-policy URL).

The source of truth is `docs/privacy-policy.html` in the NekoAI repository; this is a mirror. Copy that file over
`index.html` rather than editing here, so the two never drift.
